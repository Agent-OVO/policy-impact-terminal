# ADR-006 固定政策来源白名单与有限采集原则

状态：已接受
日期：2026年7月10日

## 固定白名单

定时采集只允许以下四个来源：

1. 中国政府网最新政策；
2. 国家发展改革委政策文件库；
3. 工业和信息化部政策文件库；
4. 国家数据局政策发布。

地方政府、其他部委、媒体、协会、公众号、商业资讯、公司新闻和搜索结果不得因为一次临时查询自动进入定时采集。

## 新增固定来源条件

必须同时满足：

- 四来源长期无法覆盖用户持续关注的核心投资领域；
- 缺口由连续复盘证实，而非单次遗漏；
- 来源稳定、可测试、维护成本可控；
- 有效高价值产出明显高于噪声与维护成本；
- 用户明确批准。

## 任务型补证

单份报告可临时使用其他官方来源、公司公告、交易所文件和权威资料补证。补证来源只进入该报告证据链或证据卡，不进入定时爬虫白名单。

## 采集频率与上限

最终建议：

- 工作日北京时间09:30和17:30各运行一次；
- 周末默认不运行；
- 重大政策期由管理员人工触发；
- 单来源列表扫描上限60条；
- 规则过滤后全局候选上限24条；
- 单次新增规范政策原文上限12条；
- 单日进入L2/L3人工分析队列上限3条；
- 待分析高价值队列上限8条，超过后暂停自动入队并要求人工清理优先级。

这些上限属于集中配置，不硬编码在多层代码中。抓取和入库不调用模型。

## 分层

- L0：新闻、解读、图解、答记者问、会议、人事、普通表彰及无产业意义批复，排除且零Token；
- L1：正式但投资产业关系弱，只归档元数据、原文和哈希，零Token；
- L2：方向化分析；
- L3：价格、税收、补贴、名单、项目、试点、标准、准入、采购、资金、强制监管和明确时间表等深度分析。

L0/L1优先使用确定性规则。只有规则冲突且可能影响高价值政策入队时，才允许使用小额“疑难分类”模型预算。

## 来源健康

每个来源记录：

- 最近成功时间；
- 列表候选数；
- 正文提取成功率；
- 去重和新增数量；
- 连续失败次数；
- 解析器版本；
- 最近异常摘要。

任一白名单来源失败时，本次运行标记为`degraded`；连续两次失败发出告警。出现“有候选但正文提取为0”时必须失败或阻断入库，不能只打印warning后保持绿色。

## 漏抓治理

每月按用户关注产业进行一次缺口复盘，抽查是否存在四来源未覆盖的重要正式政策。复盘结果用于人工补录和评估是否满足新增来源条件，不自动扩源。

## 后果

相比当前小时级采集，最大自动发现延迟约为一个工作日内，但政策并非秒级行情。该方案显著降低噪声、候选堆积和维护成本，同时通过健康监控、人工触发和月度缺口复盘控制重大漏抓风险。
