# ADR-001 产品定位与用户边界

状态：已接受
日期：2026年7月10日

## 决策

系统定位为邀请制、内部使用、以个人投资研究为主并允许少量协作用户的政策驱动投资研究辅助系统。

系统不是公众政策资讯网站，不提供自动交易、实时荐股或收益承诺。

## 用户与权限

- `owner/admin`：配置、邀请、发布、回滚、治理和审计；
- `analyst`：读取原文、形成草稿、提交审核，不直接发布；
- `viewer`：只读已发布报告、聚合结果和观察池。

阶段八关闭公开注册，改为管理员邀请。正式用户需要登录。未来如需公开只读报告，应建立独立发布面和新的ADR，不复用内部账户边界。

## 账户与非核心功能

长期账户应使用可恢复的真实身份渠道，不再依赖合成邮箱。系统应提供停用和删除流程，并按审计要求处理历史修订中的作者标识。

头像、装饰性通知、订阅等级和重复退出入口不是核心能力。旧前端冻结期不扩展；新前端仅在有明确业务需求时保留。

## 使用事件治理

默认只收集安全、可用性和核心功能失败所需的最小事件。细粒度阅读路径分析默认关闭，或仅对明确参与内部测试的用户启用。

建议保留期：

- 原始使用事件：90天；
- 去标识化聚合指标：最多12个月；
- 安全和发布审计：按运行治理要求单独保存。

## 后果

该决策降低账户滥用、隐私治理和公众内容责任，但意味着系统不以公开流量增长为目标。
