# 能源与制造政策主线合成简报

日期：2026年7月28日  
版本：v1.0  
定位：5—10分钟决策速读，不替代单项政策报告、公司基本面研究或交易判断。

## 一、核心判断

当前能源与制造政策已经形成一条连续制度链：

```text
可再生能源供给扩张
→ 重点行业强制消费与绿证履责
→ 输配电价和网络成本重置
→ 园区及多法人用户绿电直连
→ 零碳工厂与智能工厂项目化改造
→ 工业节能监察、年度评价和退出机制
→ 核电等长期资产责任与费用前置
```

这条主线不能简单概括为“新能源利好”或“设备需求增长”。它同时包含三类作用：

1. **强制成本和合规约束**：绿电消费、输配电费、能效监察、零碳指标、退役费用等进入企业成本和责任体系。
2. **项目与改造需求**：专线、变电、储能、计量、集控、能碳管理、工业软件、工业人工智能和高效用能设备可能形成建设需求。
3. **证据门槛**：只有项目清单、主责单位、投资额、采购中标、合同、验收和收入出现后，才能把产业方向升级为公司经营结论。

因此，终端下一阶段应优先跟踪**价格、硬指标、正式名单、项目和合同**，而不是继续扩大主题公司清单。

## 二、八项政策如何构成一条主线

## 三、哪些变化会直接改变价格、成本和强制责任

### 1. 工商业电费不能再用全国平均值理解

第四监管周期输配电价按省份、电压等级和用电制度分别核定。两部制用户不仅承担电量电价，还承担需量或容量电价。实际成本取决于：

- 接入电压等级；
- 报装容量和最大需量；
- 负荷率和峰谷特征；
- 区域电网容量费、线损和交叉补贴；
- 省级执行细则及企业实际账单。

因此，判断某类高耗能企业电费变化时，必须取得同口径的第三、第四监管周期价表和2026年8月后的账单，不能直接判断“全国普涨”或“全国普降”。

### 2. 绿电消费从倡导转为履责

重点行业企业的可再生能源消费将按年度目标核算。企业可以通过自发自用、绿电直连、绿电交易和绿证等完成履责，但未完成后只有三个月市场化补足期，逾期可能面临约谈、通报、信用记录和重点监管。

这意味着绿证和绿电成本将逐步从可选ESG支出转化为部分行业的制度性成本，但具体影响仍取决于年度行业范围和比例。

### 3. 工业能效约束已进入具体企业名单

2026年度国家任务清单已点名具体企业和设施。被列入清单只代表接受监察，不等于违规或处罚；但企业需要面对能耗限额、设备能效、生产过程能耗、产品能效和整改复核。

真正可能改变经营结果的后续事实是：

```text
检查结论
→ 违规或不达标事实
→ 整改期限与技术方案
→ 设备更新或系统改造
→ 采购、中标、验收和付款
```

### 4. 零碳与退役责任进入长期成本

零碳工厂要求真实能源结构、物理绿电和持续MRV，不能单纯购买碳抵销。核电退役办法则把未来退役费用提前计入生产成本并逐年提取。两类政策都表明，低碳与安全责任正在从阶段性项目转向资产全生命周期成本。

## 四、哪些环节可能形成项目、设备和数字化投入

### 1. 多用户绿电直连的项目资产最明确

独立主责单位原则上需要组织或投资：

- 新能源电源；
- 专用线路和变电设施；
- 储能；
- 集控和运营平台；
- 双向分时计量；
- 调度、通信和网络安全设施；
- 小时级绿电分配与绿证溯源。

但这些是项目构成，不等于任何设备或软件供应商已经获得订单。第一道公司证据应来自项目核准备案和主责单位，第二道证据才是采购中标与合同。

### 2. 零碳工厂与智能工厂可能汇合为同一改造项目

零碳工厂关注能碳核算、非化石能源、工艺减排、供应链和信息披露；智能工厂关注数字化设备、工业软件、工业模型、智能体、数据协同和经营绩效。实际项目中二者可能共同推动：

- 能源计量和碳核算；
- 高效电机、锅炉、风机、泵和空压机更新；
- 生产线自动化和智能控制；
- 工业数据平台、模型和智能体；
- 供应链碳数据和产品碳足迹；
- 项目集成、测试、运维和持续优化。

公司研究应优先读取申报材料中的**总投资、集成商和绩效指标**，而不是先按“工业软件”“AI”“节能设备”标签罗列公司。

### 3. 可再生能源规划的重点已从装机扩展到可靠消纳

规划同时强调海上风电、抽水蓄能、储能、电网调节、绿电绿证和绿色氢氨醇。真正优先的项目不是单一新增电源，而是能够解决：

```text
新能源供给
+ 可靠顶峰
+ 网络送出
+ 就近消纳
+ 工业和交通替代
```

因此，项目研究应把电源、网络、储能、负荷和消费责任放在同一张表中。

## 五、福建最需要关注的落地点

### 1. 海上风电与沿海能源工程

全国海上风电进入明确的开工和累计装机目标期。福建具备沿海和海洋工程条件，但终端当前只能确认国家方向，不能替福建项目数量、核准进度和设备订单作结论。应跟踪：

- 福建海上风电项目库和核准；
- 用海、海缆、登陆点和送出工程；
- 项目招标、开工和并网；
- 深远海技术路线及工程成本。

### 2. 福建工商业输配电价和实际账单

第四监管周期福建单一制电量价按不满1千伏至220千伏及以上依次为0.1833、0.1633、0.1433、0.1233和0.0883元/千瓦时；省内上网环节线损率为3.37%，外送电送出省价格为0.0220元/千瓦时。两部制用户还需结合电量、需量或容量价格分析。

下一步应选择福建典型制造企业或园区，以2026年8月前后账单做同口径复核，而不是只看价表。

### 3. 新能源装备制造同样受到能效监察

国家工业节能监察已经把光伏、风电、动力和储能电池、水电解制氢装备纳入重点产业链。福建任务清单直接点名宁德时代等主体，同时还覆盖福建锂电材料、电池、光伏玻璃和相关制造环节。

这不是“被处罚名单”，而是监管暴露事实。研究重点是制造能耗、产品能效、碳足迹、整改项目和实际资本开支。

### 4. 工业园区和出口企业可能成为绿电直连主要场景

多用户绿电直连明确面向工业园区、零碳园区、算力设施、绿色氢氨醇以及有绿色消费要求的出口外向型企业及上下游。福建应重点观察：

- 省级就近消纳距离、用户边界和上网比例细则；
- 园区主责单位及源荷合资模式；
- 专线、变电、储能和运营平台投资；
- 出口企业绿电溯源和供应链碳要求；
- 项目自用率、负荷覆盖率和实际用电成本。

### 5. 智能工厂和零碳工厂申报名单

福建制造业项目只有进入省级推荐或国家建设名单后，才具备进一步反查集成商和供应商的价值。首要证据不是企业宣传，而是：

```text
项目名称
主申报单位
总投资
建设内容
集成商
关键设备和软件
验收指标
```

## 六、为什么目前仍不能广泛映射上市公司

八项政策中，工业节能监察已经出现正式企业名单，但它代表监管对象，不代表受益公司。其余政策大多仍停留在规则、规划、申报或建设机制阶段，尚未披露足够的项目与经营证据。

从政策到公司至少需要跨过以下证据门：

```text
政策方向
→ 省级细则或正式名单
→ 具体项目和主责单位
→ 投资额与技术方案
→ 采购中标和合同
→ 交付验收
→ 收入、利润和现金流
```

任何在第二、第三步之前直接罗列设备、软件、储能、风电或绿氢概念公司的做法，都容易把产业相关性误写成公司受益。

## 七、下一阶段观察清单

按价值和确定性排序：

1. 各省重点行业可再生能源最低消费比重和省级消纳权重；
2. 福建第四监管周期输配电价执行通知及典型企业8月后账单；
3. 福建及其他省份首批多用户绿电直连细则和项目名单；
4. 国家级零碳工厂建设名单、年度方案和投资额；
5. 卓越级、领航级智能工厂名单及总投资、集成商信息；
6. 3874家工业节能监察对象的检查结果、整改要求和采购项目；
7. 海上风电、抽蓄、绿氢氨醇和送出工程的项目核准与招标；
8. 核电退役费用管理细则、首次五年评估和具体技术装备项目。

## 八、研究优先级结论

当前最值得优先投入的不是继续生成宽泛规划报告，而是三类高确定性事实：

- **价格与强制责任**：输配电价、消费比例、监察与费用提取；
- **正式项目入口**：项目名单、主责单位、总投资、集成商；
- **经营兑现证据**：采购、中标、合同、验收、收入和现金流。

只有当以上事实出现时，终端才应升级公司映射和投资方向判断。
