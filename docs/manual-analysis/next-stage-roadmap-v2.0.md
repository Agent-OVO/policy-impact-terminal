## 三、当前常态运行任务

内容迁移不再作为主线。后续报告按照生产手册逐份执行：

```text
官方原文与附件
→ 政策、产业、公司、项目证据分层
→ 严格校验
→ 回归测试
→ 治理指标
→ 人工写回
→ Pages部署
→ 线上抽查
```

持续维护指标：

- 报告和治理注册表一致性；
- 证据对象覆盖率；
- 独立公司证据覆盖率；
- pending/watch_only数量；
- 写回成功率和Pages部署成功率；
- 认证后视觉抽查覆盖率。

## 五、阶段切换与插入规则

允许高时效政策插入单份分析，但完成后回到当前主阶段。

禁止：

- 因指标压力硬凑公司证据；
- 为提高覆盖率删除合理的待验证主体；
- 将政策行业证据冒充公司业务证据；
- 将技术债与多份政策内容回炉混成同一提交；
- 跳过全量质量门直接发布。
