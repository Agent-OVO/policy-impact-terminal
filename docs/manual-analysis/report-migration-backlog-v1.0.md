# 旧报告 A/B/C 回炉清单 v1.0

## 一、分级原则

### A 类：完整回炉

适用于名单、目录、价格、监管、试点、项目、行业行动或执行机制明确，且能够形成稳定产业链和公司关系分层的政策。处理范围为全部五个关系模块，并按新方法论严格校验。

### B 类：产业方向回炉

适用于宏观规划和公共服务规划。重点补齐 `policyIndustryMap`、`industryChain`、`policyNetwork`、`investmentDirection`；`companyMap` 只保留少量高置信主体，也允许为空。

### C 类：保持轻量

适用于程序性法规、年度立法安排和行政审批便利化等不具备稳定产业链或公司映射价值的政策，不强制补五个关系模块。

## 六、执行规则

1. 每份报告仍需核验原文、附件和公司证据，不因全量严格通过而降低人工审查要求。
2. 政策原文证据只证明政策动作和产业节点；未被点名的公司必须依靠独立公司材料或降级为 `pending/watch_only`。
3. B类允许 `companyMap=[]`，不能为了页面展示硬凑公司。
4. C类不因未补五模块而视为质量缺陷。
5. 每次发布必须执行严格校验、`npm run manual:test`、构建、事实保留复核、写回和线上检查。
6. 公司排序只代表研究排队，不构成推荐等级或交易指令。
