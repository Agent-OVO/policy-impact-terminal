# 旧报告 A/B/C 回炉清单 v1.0

## 一、分级原则

### A 类：完整回炉

适用于以下政策：

- 投资研究相关性高；
- 有明确名单、目录、价格、监管、试点、项目、行业行动或执行机制；
- 可以形成稳定产业链；
- 可以区分公司关系强弱；
- 后续存在名单、标准、项目、采购、合同或地方落实信号。

处理范围：补齐全部五个关系模块，并按新方法论严格校验。

### B 类：产业方向回炉

适用于宏观规划和公共服务规划：

- 产业方向明确；
- 但项目、资金、公司和采购证据分散；
- 强行映射大量公司容易形成主题化清单。

处理范围：优先补 `policyIndustryMap`、`industryChain`、`policyNetwork`、`investmentDirection`；`companyMap` 只保留少量高置信主体，也允许为空。

### C 类：保持轻量

适用于程序性法规、年度立法安排、行政审批便利化等：

- 主要影响制度程序或政府部门；
- 无稳定产业链或公司映射价值；
- 强行生成投资方向会产生误导。

处理范围：保留现有人工分析和证据链，不强制补五个关系模块。必要时只补政策网络和“不适合公司映射”说明。

## 七、执行规则

1. 不批量自动改写全部旧报告；每份报告仍需人工核验原文、附件和公司证据。
2. A 类也不是统一模板复制，应按名单、监管、价格、行动方案等政策类型选择已完成样板。
3. B 类默认允许 `companyMap=[]`，不能为了首屏显示硬凑公司。
4. C 类不因未补五个关系模块而视为质量缺陷。
5. 每次只处理一份报告，完成严格校验、写回和线上抽查后再进入下一份。
6. 具体下一份研究标的由项目需要和用户选择共同确定，不按文件名机械执行。
