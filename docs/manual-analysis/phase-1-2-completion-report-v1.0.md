## 三、方法论改进

- 能源AI：区分能源和算力主体责任、电网与绿色算力建设、通用AI服务商和安全服务商；
- 美丽中国考核：区分地方考核压力与监测、治理、核证企业需求；
- 纺织品牌：正式名单公布前，代表企业不得写成入选卓越品牌；
- 美丽中国规划：采用方向化迁移，压缩为监测、治理、固废和绿色金融少量公司；
- 应急规划：优先生命线监测、指挥通信，装备侧保持项目驱动；
- 农业规划：优先种业、农机和数字农业，冷链物流不做泛化映射；
- 碳达峰：支持链、工业改造服务链和高耗能约束链分别表达；
- 城市更新：明确不是房地产全面刺激，核心是管网、生命线、CIM、项目库和资金机制。

## 四、统一证据边界

- 政策原文证明政策动作和产业节点；
- 未被政策点名的公司不能仅凭政策原文形成强公司证据；
- 公司层关系以独立业务材料、项目、合同或明确降级为基础；
- 规划中的装机、项目和资金目标不能直接翻译为公司收入和利润；
- 公司排序只表示研究排队。
