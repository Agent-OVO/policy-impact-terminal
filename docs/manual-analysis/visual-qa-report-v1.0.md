## 四、发现并修复的问题

### 外部公司图标请求产生控制台噪声

修复前，公司模块会尝试访问Google favicon服务和部分公司官网图标。受网络、跨域或站点404影响，单次模块切换产生23条资源加载错误。

处理方式：

- 外部公司图标改为显式开关；
- 默认关闭第三方图标请求；
- 使用本地稳定占位图标；
- 仅在明确设置以下变量时启用：

```text
VITE_ENABLE_EXTERNAL_COMPANY_LOGOS=true
```

修复后：

- 公司模块控制台错误为0；
- 页面不再依赖Google favicon服务；
- 公司卡片、矩阵和详情功能不受影响。
