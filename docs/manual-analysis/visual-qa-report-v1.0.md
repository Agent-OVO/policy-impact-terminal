## 五、发现并修复的问题

### 1. 外部公司图标请求产生控制台噪声

修复前，公司模块访问Google favicon和公司官网图标，受网络、跨域或404影响产生23条资源错误。

处理：

- 外部图标改为显式开关；
- 默认使用本地占位图标；
- 仅设置`VITE_ENABLE_EXTERNAL_COMPANY_LOGOS=true`时访问第三方图标。

修复后控制台错误为0。

### 2. 公司影响页错误使用完整兼容主体

修复前，投资方向观察使用`companyMap`，独立公司页却展示全部`companies`，导致核心公司范围和列表计数不一致。

处理：

- 完整报告公司页以`companyMap`为权威；
- `companies`只提供主体事实、证券代码、产品和公司证据；
- 公司统计统一派生自`companyMap.length`；
- validator新增计数一致性规则；
- 17份完整报告全部重新写回。

修复后，生产认证态公司卡数量、列表计数和投资观察范围完全一致。
