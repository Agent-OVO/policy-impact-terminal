## 三、当前主阶段：价值运营

阶段目标不再是增加报告数量，而是回答：

1. 当前最重要的政策主线是什么；
2. 哪些变化已经成为价格、成本和强制责任；
3. 哪些产业方向已经出现项目、名单和投资额；
4. 哪些公司关系已经获得合同、验收和经营证据；
5. 哪些判断仍应保持零公司或间接观察。

标准生产链：

```text
当前窗口收口
→ 身份与既有成果对账
→ 快速价值筛选
→ 最多3项正式分析
→ 严格质量门与生产发布
→ 跨政策主线合成
→ 用户价值复核
```

## 四、运营优先级

### 优先级1：当前窗口

所有2026年7月15日后的新候选优先处置：

- 待判断；
- 等待证据；
- 已选择分析；
- 重复或滚动更新。

目标是保持当前窗口清晰，不以历史积压挤占新政策时效。

### 优先级2：强机制政策

优先分析具备以下任一事实的政策：

- 价格或收费调整；
- 强制比例、监管、处罚或信用约束；
- 正式名单和项目；
- 财政资金、保险补偿或成本承担；
- 采购、招标、验收和退出机制；
- 可核验的公司、产品或项目主体。

宽泛规划如果与已有主线高度重合，优先进入政策网络，不重复生成大报告。

### 优先级3：证据更新

存量报告出现以下事实时优先更新：

- 省级实施细则；
- 正式项目或名单；
- 投资额和集成商；
- 采购、中标和合同；
- 评价、验收或处罚结果；
- 公司经营披露。

滚动目录和月度名单默认更新锚定报告。

### 优先级4：主线合成

每完成一批正式分析，至少形成一份5—10分钟可读的主线简报，回答：

- 政策之间如何连接；
- 哪些变化已进入成本和经营；
- 哪些仍是方向；
- 福建或重点区域如何落地；
- 下一步需要等什么证据。

## 七、公司映射和投资观察停止线

禁止：

- 因政策主题相似罗列概念公司；
- 把被监管、被点名或参加标准制定解释为确定受益；
- 把项目方向解释为设备订单；
- 把资源池、名单入围或平台上架解释为收入；
- 用公司业务能力替代本政策项目证据；
- 为提高公司覆盖率降低证据门槛。

公司关系升级顺序：

```text
主题相关
→ 政策点名
→ 项目主体
→ 采购或合同
→ 交付验收
→ 收入利润和现金流
```
